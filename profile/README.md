# ✨ Key Features

- 🃏 **Deck Profile Manager:** Save and switch between multiple build setups  
- 🧠 **Run Organizer:** Track different playthrough strategies  
- 💾 **Save Backup System:** Protect progress and run data automatically  
- 🛡 **Safe & Non-Intrusive:** No modification of core game files  
- 🌍 **Cross-Platform Support:** Windows, macOS, Linux compatible  
- ⚡ **Launch Optimization:** Faster startup and smoother mod loading  
- 🔄 **Auto Updates:** Keeps mod configurations up to date  
- 🎁 **Open-Source & MIT Licensed:** Free and community-driven
